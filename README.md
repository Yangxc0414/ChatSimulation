# 模拟即时通信系统

这是一个基于C++实现的模拟即时通信系统，模拟了QQ、微信和微博三大社交平台的核心功能，支持用户管理、好友互动、群组协作、内容发布与互动等完整社交场景。系统采用面向对象设计，通过文件存储实现数据持久化，并支持多线程并发操作。

## 项目功能

### 1. 多平台用户管理
- 跨平台注册与登录（QQ/微信/微博）
- 微信支持用户ID和微信号双重登录方式
- 个人信息维护（昵称、生日、位置等）
- 密码修改与隐私设置（朋友圈/微博可见性控制）
- 在线状态管理（在线/离线/忙碌/隐身）

### 2. 好友关系管理
- 好友添加/删除/备注修改
- 好友请求发送与处理
- 黑名单管理功能
- 跨平台共同好友查询（微信-QQ、微博-QQ/微信）
- 好友信息查询与互动状态查看

### 3. 群组协作功能
- 多平台群组创建与管理（QQ/微信/微博）
- 群成员管理（添加/移除/权限设置）
- 群组消息发送与历史记录查看
- 群组邀请与加入/退出机制
- 群组开放状态控制（开放/关闭新成员加入）
- QQ支持临时讨论组创建

### 4. 内容互动系统
- 微信朋友圈发布/查看/删除
- 微博发布/查看/删除/转发
- 点赞与评论功能
- 基于隐私设置的内容访问控制

### 5. 消息通知机制
- 实时消息发送与接收
- 消息历史记录查询
- 系统通知（好友请求/群组邀请等）

## 技术设计

### 类层次结构
- **基类**：`User_yxc` 提供用户通用功能
- **派生类**：`QQ_yxc`、`WeChat_yxc`、`Weibo_yxc` 实现平台特有功能
- **功能类**：`Group_yxc`（群组管理）、`Message_yxc`（消息处理）、`SocialMediaPost_yxc`（内容管理）
- **工具类**：`Utils_yxc`（文件操作、时间处理等辅助功能）

### 数据存储
- 采用文件系统存储所有数据，支持断电持久化
- 每个用户/群组拥有独立的文件目录结构
- 消息与内容按时间戳有序存储

### 并发处理
- 使用`mutex`和`condition_variable`实现线程安全
- 消息队列支持多用户并发操作
- 文件操作通过互斥锁保护，避免数据冲突

## 编译与运行

### 环境要求
- Windows系统（使用`winsock2.h`等Windows库）
- C++编译器（支持C++11及以上标准）
- 支持STL标准库

### 编译方法
1. 使用支持C++的IDE（如Visual Studio、Dev-C++）打开项目
2. 将所有`.cpp`文件添加到项目中
3. 编译生成可执行文件（确保链接`ws2_32.lib`库）

### 运行步骤
1. 编译成功后生成可执行文件
2. 运行程序进入登录菜单
3. 选择登录平台（QQ/微信/微博）
4. 使用预设用户登录（用户ID：1001、1002、1003、1004、1005、1006、123，默认密码均为123）
5. 通过菜单导航进行各项操作

## 使用说明

### 登录与基础操作
- 微信支持两种登录方式：用户ID登录和微信号登录
- 登录后可通过主菜单进入不同功能模块
- 系统采用多级菜单设计，可通过输入0返回上一级

### 好友管理操作
- 发送好友请求后需对方确认
- 查看共同好友需对应平台处于登录状态
- 拉黑用户后将无法发送/接收消息及查看动态

### 群组管理操作
- QQ支持创建临时讨论组
- 微信群组仅能通过邀请加入
- 群主可设置群组开放状态（开放/关闭）
- 群主拥有添加/移除管理员权限，管理员可踢出成员

### 内容发布与互动
- 朋友圈和微博支持隐私设置（公开/仅好友/私密）
- 微博特有转发功能，可附加评论
- 点赞和评论受隐私设置限制

## 注意事项

- 程序依赖特定目录结构存储数据，请确保运行目录完整
- 跨平台功能（如共同好友）需要对应平台同时登录
- 多线程操作时可能出现短暂延迟，属于正常现象
- 所有用户初始密码均为123，建议首次登录后修改
- 隐私设置变更后将立即生效，影响内容可见性
